Bu klasörü GitHub'a yükleyip Render'da Web Service olarak açabilirsin.

Start Command: npm start

Oyuncular Node.js kurmadan bu adresi tarayıcıdan açabilir.

Not: Ücretsiz Render servisleri uzun süre kullanılmazsa uykuya geçebilir.
